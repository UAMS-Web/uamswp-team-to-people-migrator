The plugin is developed by UAMS Web Services in [UAMS-Web/uamswp-team-to-people-migrator](https://github.com/UAMS-Web/uamswp-team-to-people-migrator).

- **Report a problem** in the repository's [issues](https://github.com/UAMS-Web/uamswp-team-to-people-migrator/issues). Say which version you ran, what you did, and what the tool page showed.
- **Releases** are listed on the [Releases](https://github.com/UAMS-Web/uamswp-team-to-people-migrator/releases) page.
- **Contributing:** [CONTRIBUTING.md](https://github.com/UAMS-Web/uamswp-team-to-people-migrator/blob/main/CONTRIBUTING.md) sets out the path from an issue to a merged pull request, and the [README](https://github.com/UAMS-Web/uamswp-team-to-people-migrator#readme) covers running the tests and checks.
- **These pages** are kept in [`docs/wiki/`](https://github.com/UAMS-Web/uamswp-team-to-people-migrator/tree/main/docs/wiki) and published by the Publish wiki workflow when a release is published, or by hand. Change them through a pull request; an edit made in the wiki is overwritten by the next publish.
